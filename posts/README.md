# پست‌های روزانه کانال «آخرین اخبار سئو»

هر پوشه یک روزه (`YYYY-MM-DD`) و شامل:
- `cover.png` — گرافیک اختصاصی همون روز
- `caption.txt` — متن نهایی پست به فارسی، با تگ‌های HTML تلگرام (`parse_mode=HTML`)

این پست‌ها جدا از پست‌های خودکار ساعتی (که از فیدهای خبری ترجمه می‌شن) هستن؛ این‌ها پست‌های ویژه‌ی روزانه‌ن که با بررسی دستی خبر انتخاب و نوشته می‌شن، بعد از طریق Edge Function در Supabase به کانال تلگرام ارسال می‌شن (عکس اول، بعد متن).
