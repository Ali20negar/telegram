‏🔴 API قدیمی فروشگاهی گوگل غیرفعال شد؛ فروشگاه‌ها باید مهاجرت کنن

‏◆ از اول سپتامبر ۲۰۲۶، Content API for Shopping قدیمی داره با خطا مواجه میشه؛ باید به Merchant API جدید مهاجرت کنی.
‏◆ فقط کسایی که محصول رو با برنامه‌نویسی (نه دستی یا از طریق شیت) آپلود می‌کنن تحت‌تاثیرن.

‏💡 اگه فید محصولت رو با API می‌فرستی، همین امروز وضعیت مهاجرتت به Merchant API رو چک کن.
