# قالب استاندارد گرافیک پست‌ها

`post-cover-template.svg` نسخه‌ی تأییدشده‌ی نهایی (گزینه‌ی «C - اسپات‌لایت تیره»، با لمس‌های لوکس‌تر) هست. برای پست جدید:

1. این فایل رو کپی کن.
2. فقط این بخش‌ها رو عوض کن:
   - متن کیکر (خط بالا، بعد از خط تیره‌ی طلایی)
   - تیتر اصلی (باید کاملاً فارسی باشه، بدون کلمه‌ی انگلیسی وسطش)
   - محتوای بج‌ها (اسم انگلیسی محصول/برند، رنگ سبز=مثبت/جدید با glow، رنگ قرمز=منفی/قدیمی با خط خورده)
   - خط توضیح کوتاه زیر بج‌ها
   - تاریخ/مهلت پایین صفحه (بعد از بولت طلایی)
3. لوگوی کانال (`assets/channel-logo.png`) و همه‌ی رنگ‌ها/گرادیان‌ها/فیلترها (پس‌زمینه، قاب طلایی، گرین، اسپات‌لایت طلایی و فیروزه‌ای) رو دست نزن — این‌ها هویت بصری ثابت کاناله.
4. با `node scripts/render-cover.js templates/post-cover-template.svg posts/YYYY-MM-DD/cover.png` (بعد از کپی و ادیت) رندر کن.
