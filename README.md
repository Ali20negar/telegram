# کانال تلگرام «آخرین اخبار سئو»

زیرساخت اتوماسیون کانال [@vorkaSeo](https://t.me/vorkaSeo).

## اجزا

- **`supabase/functions/post-seo-news/`** — Edge Function که هر ساعت (۸ صبح تا ۹ شب به وقت آتلانتا) سه فید خبری سئو رو چک می‌کنه، تازه‌ترین خبر پست‌نشده رو پیدا، ترجمه و طبق قالب کانال می‌چینه، عکس منبع رو اول و متن رو بعدش به کانال می‌فرسته. کاملاً رایگان، بدون کلید API.
- **`posts/`** — پست‌های ویژه‌ی روزانه که با بررسی دستی خبر انتخاب می‌شن و گرافیک اختصاصی دارن.

## دیتابیس (Supabase)

- جدول `posted_news` جلوی تکراری ارسال‌شدن خبرها رو می‌گیره.
- توکن ربات، آیدی کانال، و سکرت اجرای زمان‌بندی‌شده در **Supabase Vault** ذخیره شدن (نه در کد).
- زمان‌بندی از طریق `pg_cron` + `pg_net`، مستقیم داخل دیتابیس Supabase.
