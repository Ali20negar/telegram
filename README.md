# کانال تلگرام «آخرین اخبار سئو»

زیرساخت اتوماسیون کانال [@vorkaSeo](https://t.me/vorkaSeo).

## چطور کار می‌کنه

هر ساعت (۸ صبح تا ۱۲ شب به وقت ایران) یه روتین خودکار (Claude Code Routine، مستقل از هر دستگاه شخصی) این کارها رو انجام می‌ده:

1. با جست‌وجوی وب یه خبر تازه‌ی سئو/گوگل/AI پیدا می‌کنه (با چک جدول `posted_news` و پوشه‌ی `posts/` جلوی تکرار گرفته می‌شه).
2. یه کپشن فارسی کوتاه می‌نویسه.
3. برای تصویر: بیشتر مواقع با `scripts/make-cover.py` یه گرافیک برند می‌سازه (۱۰ قالب شیشه‌ای/تکنولوژیک، انتخاب تصادفی وزن‌دار)، بعضی مواقع هم مستقیم از عکس واقعی خبر استفاده می‌کنه تا طبیعی بمونه. اگه ویدیوی رسمی سبک (زیر ۵۰ مگابایت) مرتبط بود، اون رو می‌فرسته.
4. فایل‌ها رو توی همین ریپو کامیت می‌کنه.
5. از طریق دیتابیس Supabase (که به تلگرام دسترسی داره) مستقیم پست رو می‌فرسته — عکس/ویدیو و متن توی یه پیام واحد.

کاملاً رایگان، بدون کلید API پولی، و کاملاً روی سرورهای ابری اجرا میشه (نه روی کامپیوتر شخصی کسی).

## اجزا

- **`scripts/make-cover.py`** — سازنده‌ی گرافیک پست‌ها. مستندات کامل در `scripts/README.md`.
- **`posts/`** — آرشیو پست‌های ارسال‌شده (گرافیک + کپشن هرکدوم).
- **`assets/channel-logo.png`** — لوگوی واقعی کانال که توی همه‌ی گرافیک‌ها استفاده میشه.
- **`supabase/functions/post-seo-news/`** — نسخه‌ی قدیمی‌تر خودکارسازی (فعلاً غیرفعال، جایگزینش روتین بالاست). برای مرجع نگه داشته شده.

## دیتابیس (Supabase)

- جدول `posted_news` جلوی تکراری ارسال‌شدن خبرها رو می‌گیره.
- توکن ربات، آیدی کانال، و سکرت‌ها در **Supabase Vault** ذخیره شدن (نه در کد).
- ارسال واقعی به تلگرام از طریق `pg_net` مستقیم داخل دیتابیس Supabase انجام میشه (چون این محیط توسعه به تلگرام دسترسی مستقیم نداره).
