# رندر گرافیک پست‌ها

## `make-cover.py` (روش اصلی و توصیه‌شده)

یه پست‌کاور آماده می‌سازه با انتخاب تصادفی (وزن‌دار) از بین ۱۰ قالب شیشه‌ای/تکنولوژیک:

```
python3 scripts/make-cover.py \
  --kicker "دسته‌بندی کوتاه" \
  --headline "تیتر کاملاً فارسی، بدون کلمه‌ی انگلیسی وسطش" \
  --badge-win "New Thing" --badge-lose "Old Thing" \
  --desc "یک جمله‌ی کوتاه توضیح" \
  --footer "برچسب یا تاریخ" \
  --out posts/YYYY-MM-DD/cover.png
```

اگه خبر ساختار «قدیم به جدید» نداره، به‌جای `--badge-win/--badge-lose` از حالت آماری استفاده کن:

```
  --stat-number "2.5B" --stat-label "کاربر ماهانه AI Overviews"
```

نکات:
- **انتخاب قالب کاملاً خودکار و تصادفیه** (۱۰ گزینه، قالب‌های ۱، ۲، ۵، ۶، ۷، ۹، ۱۰ شانس بیشتری دارن). برای اجبار به یه قالب خاص: `--variant N` (۱ تا ۱۰).
- فونت Vazirmatn و لوگوی کانال به‌صورت خودکار امبد میشن، نیازی به تنظیم اضافه نیست.
- رندر با کیفیت ۲برابر (retina) انجام میشه.
- خروجی PNG با ابعاد ۲۴۰۰×۱۵۰۰ (نسبت ۱۶:۱۰) هست.

## `render-html-cover.js`

اسکریپت پایه‌ی رندر HTML→PNG با Chromium که `make-cover.py` داخلی صداش می‌زنه. مستقیم صداش نزن مگر برای یه HTML سفارشی جدا.
